## 🚀 How to Run Locally

### Option 1: Direct File Open (Zero Install)
Simply double click [index.html](file:///d:/portfolio/index.html) or open it in Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Option 2: Using Node.js (Included Server)
Open PowerShell or Terminal in `d:\portfolio` and run:

```bash
npm start
```
*or*
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment Options

### 1. GitHub Pages
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
2. Go to **Settings > Pages** in your GitHub repository.
3. Select `Branch: main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/portfolio/`.

### 2. AWS S3 + CloudFront (Naveen's Cloud Specialization!)
1. Create an AWS S3 bucket named `naveenkumar-portfolio` and enable static website hosting.
2. Upload all files from `d:\portfolio` into the bucket.
3. Create an **AWS CloudFront** distribution pointing to the S3 bucket as origin.
4. Set default root object to `index.html`.
5. Enjoy lightning-fast global edge delivery with SSL!

### 3. Vercel or Netlify
- Drag and drop the `d:\portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant global deployment.
